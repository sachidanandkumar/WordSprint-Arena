# Word Warriors\n\nReal-time multiplayer clue-and-guess word game. One player sees the secret word and gives verbal clues; the other players guess.\n\n## Run locally\nRequires Node.js 20+.\n```bash\nnpm install\nnpm start\n```\nOpen http://localhost:3000 in two browser windows. Create a room in one and join using its code in the other.\n\n## Deploy free on Render\n1. Create a GitHub repository named `word-warriors`.\n2. Upload the contents of this folder to the repository.\n3. In Render, select **New + → Blueprint**, connect the repository and deploy. Render reads `render.yaml`.\n4. Open the public `onrender.com` URL and test with two devices.\n\n## Notes\n- Rooms are held in server memory; a restart/redeploy clears active games.\n- This starter is designed for one server instance, not horizontal scaling.\n- Reconnection does not restore an old player session; disconnected players may need to rejoin.\n- Clues are spoken or shared outside the app; in-app voice chat is not included.\n- Free hosting may sleep when idle, so the first visit can be slow.\n
